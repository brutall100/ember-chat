    How a letter travels

    1. I

      Write

      Pick a name and write your letter. The name is remembered in your browser for next time.

    2. II

      Seal

      With the Node.js server, each letter is saved to MySQL using safe placeholder queries.

    3. III

      Deliver

      Socket.IO hands it to everyone in the room instantly. On GitHub Pages a friendly demo writes back.
